VIDEO TO ZIP - FRONTEND ONLY

Cara menjalankan:
1. Ekstrak folder/file ZIP ini.
2. Buka index.html di browser (Chrome/Edge/Firefox).
3. Klik Pilih Video atau drag-and-drop video.
4. Klik Buat File ZIP, lalu Download ZIP.

Catatan:
- Tidak membutuhkan backend atau database.
- JSZip dimuat dari CDN, jadi perlu koneksi internet saat membuka halaman.
- File video diproses lokal di browser dan tidak diunggah ke server.
- Untuk file sangat besar, kebutuhan RAM browser bisa tinggi.
